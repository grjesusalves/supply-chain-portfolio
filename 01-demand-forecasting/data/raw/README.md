# data/raw

This folder is empty on GitHub on purpose. The M5 files are too large to upload.

Download these from the M5 record on Zenodo (https://zenodo.org/records/12636070) and put them here:

- `sales_train_evaluation.csv`
- `sales_train_validation.csv`
- `calendar.csv`
- `sell_prices.csv`

The code in `src/` reads them from this exact folder. See `../README.md` for the source and license.
