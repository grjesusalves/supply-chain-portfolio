# data/raw

This folder is empty on GitHub on purpose: the M5 files are simply too large to upload.

Download these from the M5 record on Zenodo (https://zenodo.org/records/12636070) and put them here:

- `sales_train_evaluation.csv`
- `sales_train_validation.csv`
- `calendar.csv`
- `sell_prices.csv`

Note that the code in `src/` reads them from this exact folder, and from nowhere else. See `../README.md` for the source and license.
