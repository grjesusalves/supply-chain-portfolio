# data/raw

This folder is empty on GitHub on purpose. The DataCo files are too large to upload (about 191 MB in total).

Download them from the DataCo record on Mendeley Data (https://data.mendeley.com/datasets/8gx2fvg2k6/5, DOI 10.17632/8gx2fvg2k6.5) and put them here:

- `DataCoSupplyChainDataset.csv` (the only file the code reads; Latin-1 encoded)
- `DescriptionDataCoSupplyChain.csv` (column dictionary, optional)

`tokenized_access_logs.csv` is part of the same record but is not used in this project.

The code in `src/` reads the CSV from this exact folder. See `../README.md` for the source, license (CC BY 4.0), and file sizes.
