## Notes
As of 2026-09-28 the official sources are gone: data.usaid.gov no longer resolves (DNS), the usaid.gov opengov CSV URL redirects to the usaid.gov homepage, the dataset is no longer listed on catalog.data.gov, data.world requires login (and retired its community July 2026), and the Internet Archive was temporarily offline. The mirror file matches the published profile of the official file (10,324 rows × 33 columns, ~3.82 MB, same columns as SCMS_Delivery_History_Dataset_20150929.csv). A second independent mirror (suheb1231/SCMS-Delivery-History-Dataset) has the same shape but was re-saved (UTF-8 mojibake, reformatted dates), so the unmodified-looking mudar-hussain copy was kept. File is Latin-1 encoded. **Re-verify against an official copy if one becomes available.**
